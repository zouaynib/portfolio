# Artwork

Save your paintings here using these exact filenames:

    moroccan-teapot.jpg      Teapot and zellige
    blue-door.jpg            Blue door, bougainvillea
    lemons.jpg               Lemons in blossom
    sunflowers.jpg           Sunflowers, after Van Gogh
    blossoms-lilac-jug.jpg   Blossoms in a lilac jug
    seascape.jpg             Evening sea
    pink-rose.jpg            Rose
    rose-open.jpg            Rose, opening

Crop to the canvas edge where the photo shows an easel, a table or a garden
behind it — the frame in the studio IS the frame, so background clutter reads
as part of the painting. JPG, around 1200px on the long edge is plenty.

Frames size themselves to each image's aspect ratio, so portrait, landscape and
square all hang correctly. A frame with no file shows a placeholder naming the
file it wants, so you can add them one at a time.

To rename, retitle or rearrange, edit src/data/artwork.js. `wall` is 'back',
'left' or 'right'; pieces space themselves evenly along whichever wall they are
on, in list order.
